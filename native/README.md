# KinoXPlayer для macOS

KinoXPlayer — видеопроигрыватель для macOS с двумя независимыми дорожками внешних субтитров. Воспроизведение и локальная проверка синхронизации выполняются на Mac. Онлайн-поиск используется только по явной команде пользователя.

## Возможности

- открытие видео через диалог, Finder или drag-and-drop;
- две независимые дорожки SRT/WebVTT: загрузка, замена, отключение и удаление;
- локальный поиск субтитров рядом с фильмом с проверкой по реальному аудио;
- поиск и загрузка субтитров из каталога OpenSubtitles.com на русском, немецком и других языках;
- точный онлайн-поиск по отпечатку открытого видео без загрузки самого фильма;
- автоматическая подгонка любой загруженной дорожки по речи в фильме;
- локальное смысловое связывание эквивалентных фраз S1 и S2 без разрыва контекста;
- распознавание постоянного сдвига, постепенного дрейфа/FPS и вероятно другого монтажа;
- применение найденной поправки времени без изменения исходного файла SRT/VTT;
- индивидуальная синхронизация S1 и S2 с шагом 0,5 секунды и точным ползунком;
- отдельные цвет и размер шрифта для обеих дорожек, фон, жирность и положение;
- системные элементы управления AVPlayer, полноэкранный режим и скорость 0,5–2×;
- сохранение настроек, громкости и позиции просмотра;
- горячие клавиши: `Space`, стрелки, `M`, `1`/`2`, `[`/`]`, `Command–O`;
- интерфейс на русском языке и поддержка VoiceOver для основных элементов.

Настройки открываются стандартным сочетанием `Command–,`. Положительный сдвиг задерживает появление субтитров, отрицательный показывает их раньше.

### Связывание фраз S1 ↔ S2

В **Настройки → Субтитры → Связывание фраз** можно один раз установить локальную языковую модель размером около 245 МБ. После установки функция включается автоматически и работает без интернета. Текст субтитров остаётся на Mac и никуда не отправляется.

Сначала приложение выполняет обычную синхронизацию обеих дорожек с видео, затем сравнивает фразы по времени, порядку и смыслу. Связанные переводы показываются одновременно по интервалу S1. Если уверенной пары нет, реплика отображается отдельно — рядом с ней никогда не подставляется строка с другим контекстом. Исходные SRT/VTT не изменяются.

Статус виден в правой панели в секции **«Связь S1 ↔ S2»**. Там можно посмотреть долю связанных фраз и запустить повторное сопоставление. Первый анализ полного фильма на Apple Silicon может занять несколько десятков секунд; готовый результат и смысловые векторы сохраняются в производном кэше и при следующем открытии загружаются значительно быстрее.

## Запуск готового приложения

Исходники репозитория не содержат готовую `.app`. Сначала [соберите приложение](#сборка-скриптом); скрипт создаст папку `native/dist` и поместит в неё результат.

1. Откройте папку `native/dist` в Finder.
2. Запустите `KinoXPlayer.app`.
3. Откройте видео через меню приложения или сочетанием `Command–O`.
4. Загрузите первую и вторую дорожки субтитров соответствующими кнопками или командами меню.

По умолчанию после загрузки каждой дорожки приложение само сравнивает реплики с речью, исправляет начальный сдвиг и накопительный дрейф, а затем показывает найденную поправку и уверенность в правой панели. Для повторной проверки нажмите «Подогнать автоматически» в карточке S1 или S2. «Сбросить всё» удаляет автоматическую и ручную коррекцию. Автоподгонку после загрузки можно отключить в **Настройки → Субтитры**, оставив ручной запуск доступным.

Чтобы найти подходящие файлы автоматически, откройте правую панель и нажмите «Найти подходящие субтитры…». Выберите папку с SRT/VTT и запустите проверку. Первый анализ фильма обычно занимает 20–40 секунд; повторная проверка использует сохранённый в памяти профиль и выполняется быстрее. Проверка речи работает системными средствами macOS локально: видео и субтитры не загружаются в интернет, разрешение на микрофон не требуется.

Результаты «Смещение» и «FPS» можно сразу назначить в S1 или S2 — приложение применит найденную поправку автоматически. Исходный файл субтитров при этом остаётся без изменений. Результат является вероятностным: музыкальные сцены, аудиокомментарии и сильно отличающийся дубляж иногда требуют ручной проверки. Коррекция с недостаточной уверенностью не применяется автоматически.

### Поиск в интернете

В окне поиска переключитесь на вкладку «В интернете», выберите языки и нажмите «Найти». Сначала показываются варианты, найденные для того же видеофайла, затем результаты по названию. Скачивание начинается только после назначения выбранного результата в S1 или S2. Для каждого открытого фильма приложение создаёт отдельную постоянную папку `~/Library/Application Support/KinoXPlayer/Downloaded Subtitles/v1/<Название фильма — короткий код>/` и сохраняет интернет-субтитры в неё. Короткий стабильный код не даёт смешать разные фильмы с одинаковым названием. Системное окно «Загрузить S1/S2» сразу открывается в папке текущего фильма. Приложение запоминает привязку и восстанавливает S1/S2 при следующем открытии; старые файлы версии 1.4 при использовании безопасно копируются из общего корня в соответствующую папку фильма. Кнопка «Папка фильма» открывает её в Finder. Для выбранного результата доступны «Показать в Finder» и «Сохранить копию…»; те же действия находятся в меню «Файл» карточки S1/S2.

Онлайн-каталог требует один API-ключ приложения OpenSubtitles.com. Для личной копии создайте Consumer с именем `KinoXPlayer` в разделе [API Consumers](https://www.opensubtitles.com/en/consumers) и вставьте ключ в защищённое поле приложения. Ключ и пользовательская сессия хранятся в Связке ключей macOS. Пароль OpenSubtitles не сохраняется. Поиск не имеет суточной квоты, но число скачиваний определяется вашей учётной записью и сообщается самим сервисом.

При онлайн-поиске OpenSubtitles получает IP-адрес, версию приложения, выбранные языки, введённое название, размер файла и 16-символьный отпечаток, рассчитанный по началу и концу видео. Полный путь, само видео и его аудио в сеть не отправляются. Локальная вкладка продолжает работать полностью без интернета и API-ключа.

Собранное локально приложение подписывается временной ad-hoc подписью. Она подходит для запуска на вашем Mac, но не заменяет подпись Developer ID и нотарификацию для публичного распространения. Если macOS блокирует приложение, полученное через интернет, нажмите его правой кнопкой, выберите «Открыть» и подтвердите запуск либо воспользуйтесь разделом «Конфиденциальность и безопасность» в Системных настройках.

## Сборка в Xcode

Требуется Xcode с macOS SDK и установленными инструментами командной строки. Проект сам загружает закреплённую совместимую версию Swift-пакета токенизации при первой сборке.

1. Откройте `native/KinoXPlayer.xcodeproj` в Xcode.
2. Выберите схему `KinoXPlayer` и устройство запуска `My Mac`.
3. Нажмите `Command–R` для сборки и запуска.
4. Для ручной Release-сборки выберите **Product → Archive** либо измените конфигурацию схемы на `Release`.

Для разработки достаточно локальной подписи **Sign to Run Locally**. Учётная запись разработчика и сертификат Developer ID не требуются.

## Сборка скриптом

Из корня репозитория выполните:

```sh
./native/Scripts/build-release.sh
```

Или из папки `native`:

```sh
./Scripts/build-release.sh
```

Скрипт:

- проверяет наличие `KinoXPlayer.xcodeproj` и `xcodebuild`;
- собирает схему `KinoXPlayer` в конфигурации `Release`;
- использует временную папку для промежуточных файлов;
- ставит и проверяет ad-hoc подпись, не запрашивая Developer ID;
- помещает результат в `native/dist/KinoXPlayer.app`.

После успешной сборки приложение можно запустить командой:

```sh
open native/dist/KinoXPlayer.app
```

Если проект ещё не создан или имеет другое имя, скрипт завершится с понятной ошибкой и не изменит содержимое `dist`.

## Поддерживаемые форматы

Воспроизведение выполняет системный AVKit/AVFoundation, поэтому фактическая поддержка зависит от версии macOS, контейнера, видео- и аудиокодека. Наиболее надёжно работают:

- видео `MP4`, `M4V` и `MOV`;
- системно поддерживаемые дорожки H.264 и HEVC/H.265;
- аудио AAC и другие форматы, которые воспроизводит AVFoundation;
- внешние субтитры `SRT` и `WebVTT` (`.vtt`).

Продвинутые эффекты ASS/SSA, караоке и сложная типографика не поддерживаются как часть формата субтитров. Внешний вид каждой из двух дорожек настраивается средствами самого приложения.

## Ограничения AVKit

- Контейнер `MKV` системно не поддерживается AVKit надёжным образом. Файл может не открыться даже тогда, когда его видео закодировано в H.264 или HEVC.
- `AVI`, `WebM` и редкие аудио- или видеокодеки также могут не воспроизводиться. Приложение не перекодирует такие файлы автоматически.
- Две внешние дорожки отображаются собственным слоем приложения и работают в обычном и полноэкранном режимах.
- Системный режим Picture in Picture обычно выводит только видеослой AVKit. Пользовательские двойные субтитры в PiP могут отсутствовать.
- Ad-hoc подпись предназначена для локального запуска. Для передачи приложения другим пользователям без предупреждений Gatekeeper потребуются Developer ID и нотарификация, которые сборочный скрипт намеренно не использует.
